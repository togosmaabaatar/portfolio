An English-first, bilingual portfolio for independent business website development, web applications, AI tools and digital presence. Custom charcoal / lavender design, responsive project previews, case studies, services, FAQs and email inquiries.

## Run and build

```sh
python3 -m http.server 8088 --bind 127.0.0.1
sh scripts/build.sh
```

The production build serves `dist/`. No dependencies or install step. `scripts/generate-site.py` generates the HTML and `projects.json` from the maintained English / Mongolian content. Run it after changing content. `script.js` implements interactions; `style.css` controls layout.
